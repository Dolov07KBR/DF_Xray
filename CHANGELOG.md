# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.4.0] — 2026-11-14

Релиз про создание серверов: вместо ручного заполнения десятка полей — пресеты по
протоколам и каталог SNI с проверкой доменов.

### Добавлено

- **Автонастройка ноды (пресеты)**: `GET /api/nodes/meta` отдаёт восемь сценариев —
  `reality-vision`, `reality-xhttp`, `reality-grpc`, `tls-ws`, `tls-grpc`,
  `vmess-ws-tls`, `trojan-tls`, `plain-tcp`. В форме сервера сценарий выбирается
  карточкой и заполняет протокол, транспорт, безопасность, порт, `path` / `serviceName`
  и SNI; поля остаются редактируемыми. Создание ноды по пресету:
  `POST /api/nodes {"name": "…", "address": "…", "preset": "tls-ws"}`.
- **Серверная валидация конфигурации** (`app/nodecfg.py`): несовместимые сочетания
  отклоняются с 400 и объяснением — Reality без SNI, WebSocket у Reality, Vision-flow
  у VMess/Trojan, `path` у TCP, неизвестный пресет. Ничего не «чинится» молча.
- **Каталог SNI**: `GET /api/sni` (13 встроенных доменов + свои), поиск, TLS-проба
  домена (TLS 1.3, ALPN, задержка, вердикт), случайный SNI. Свои домены добавляются
  через `POST /api/sni {"domain": "…"}` — идемпотентно, с сохранением в настройках
  панели (`custom_sni`), и удаляются через `DELETE /api/sni/{domain}`.
- **Панель SNI прямо в форме ноды**: поиск, добавление домена, кнопка «Проверить»
  (использует `POST /api/reality/scan`), выбор домена кликом, подсветка текущего,
  источник «встроенный / свой».
- `sni.remember()` запоминает последние использованные домены и подсказывает их
  первыми; при смене протокола, транспорта или безопасности формы ноды Vision-flow
  снимается автоматически, чтобы PATCH не ломал конфиг.
- Документация: новый раздел README «Автонастройка ноды и выбор SNI» с таблицей
  пресетов, скриншоты `docs/screenshots/node-presets.png` и `sni-panel.png`.

### Изменено

- Форма ноды: вместо ручного ввода протокола/транспорта/безопасности — блок
  автонастройки, SNI с `datalist` и кнопками «Список» / «Случайный».
- `PATCH /api/nodes/<id>` мержит присланные поля с текущей записью и прогоняет ту же
  валидацию, что и создание.
- Версия панели, агента и установщика — 1.4.0.

### Исправлено

- Добавление своего SNI в панели больше не отправляет форму ноды (кнопки внутри
  `<form>` получили `type="button"`), а панель не перерисовывает поле ввода при
  загрузке списка.
- Удаление своего SNI не закрывает форму ноды: подтверждение через диалог заменено
  на мгновенное удаление из списка (домен легко вернуть).
- Строка SNI без проверки показывает «не проверялся» вместо пустого статуса,
  задержка не рисуется нулём, причина недоступности — в подсказке.

## [1.3.0] — 2026-11-14

Релиз про эксплуатацию: безопасность входа, автоматизация, уведомления,
вывод серверов из работы и проверка под нагрузкой.

### Добавлено

- **Двухфакторная аутентификация (TOTP)** для администратора: QR-код, ручной
  секрет, 8 одноразовых резервных кодов, отдельный шаг входа с `challenge`-токеном
  (5 минут), окно ±1 шаг на дрейф часов. Включение и выключение 2FA завершают сессии.
- **API-токены** (`dfx_…`) с уровнями доступа `read` (только GET/HEAD) и `write`,
  сроком действия и отзывом: для мониторинга, бэкапов, CI и ботов. В базе хранится
  только SHA-256 хэш, значение показывается один раз.
- **Уведомления** в Telegram и/или webhook о событиях `node_offline`,
  `node_recovered`, `user_limit`, `update_available`. Фоновый воркер раз в 90 секунд,
  состояние в `notify_state` — без повторов и спама. Кнопки «Тестовое сообщение»
  и «Проверить события сейчас».
- **Автовыпуск TLS-сертификатов** при установке TLS-ноды: `certbot --standalone`
  на домен из SNI, симлинки в `/etc/xray/cert`, e-mail для Let's Encrypt в настройках.
- **Drain ноды**: сервер выводится из новых подписок, не разрывая текущие
  подключения; бейдж в карточке, поле `drain` / `drained_at` в API.
- **Миграция клиентов** между нодами одной кнопкой (`POST /api/nodes/<id>/migrate`):
  наборы `node_ids` переводятся на новый сервер, лимиты и статистика сохраняются.
- **Сортировка подписки по задержке**: TCP-проба до нод с кэшем 5 минут,
  ближайшие первыми, недоступные в конце, поле `latency_ms` в ссылке.
  Отключается настройкой `sub_sort_by_latency`.
- **Нагрузочный тест** `tools/loadtest.py` (stdlib) с профилями `panel`, `agent`,
  `sub` и документацией: [docs/LOADTEST.md](docs/LOADTEST.md).
- Документация: [docs/SECURITY.md](docs/SECURITY.md) (2FA, токены, TLS),
  [docs/NOTIFICATIONS.md](docs/NOTIFICATIONS.md), [docs/OPERATIONS.md](docs/OPERATIONS.md)
  (drain, миграция, латентность).

### Изменено

- Схема БД: версия 4 — таблицы `login_challenges`, `api_tokens`, колонки
  `totp_*` в `admins`, `drain` / `drained_at` в `nodes`, настройки
  `notify_*`, `sub_sort_by_latency`, `acme_email`. Миграция выполняется
  автоматически при старте, данные сохраняются.
- Вход в панель: при включённой 2FA первый запрос возвращает `totp_required`
  и `challenge`, второй принимает `challenge` + `code` (или резервный код).
- Скрипт установки ноды: при TLS-ноде сам ставит `certbot` и выпускает сертификат,
  ошибки выпуска не прерывают установку.
- Подписки: ссылки сортируются по задержке (по умолчанию включено).

### Исправлено

- `qr.svg()` возвращает строку — убрано лишнее декодирование в 2FA.
- `build_links()` корректно работает с нодами без поля `drain` (тестовые словари).
- Миграция схемы на очень старых базах больше не падает на отсутствующих таблицах.

## [1.2.0] — 2026-11-14

### Добавлено

- Мультисервер: установка ноды одной командой, агент как systemd-сервис,
  heartbeat-метрики (uptime, LA1, память, версия Xray/агента, ревизия конфига),
  страница «Агенты нод», здоровье нод, трафик по серверам.
- Обновление из панели: проверка версий на GitHub, бейдж, кнопка «Обновить»
  с прогрессом и логом, самообновление в Docker, fallback `dfxray update`.
- Сканер целей REALITY: домен / диапазон IP-CIDR, таблица с TLS, ALPN, обменом
  ключами, сертификатом, цепочкой и задержкой, кнопка «Выбрать» → SNI/dest.
- Новый интерфейс: боковое меню с поиском `Ctrl K`, группы разделов,
  палитра команд, документация API внутри панели.
